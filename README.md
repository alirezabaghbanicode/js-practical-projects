## <img src="./assets/flag-for-flag-united-kingdom-svgrepo-com.svg" width="22" alt="UK Flag" /> English — Portfolio Overview

Welcome to my **Practical JavaScript Projects** repository. Each application in this collection is engineered from scratch using **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)** without external frameworks—demonstrating core frontend fundamentals, clean state flow, and responsive interface design.

### Live Applications

|   #    | Project                                                        | Description & Core Concepts                                                                                                                                                                                                                                         |                                               Live Demo                                                |
| :----: | :------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------: |
| **01** | **LedgerFlow — Expense & Budget Tracker**                      | Real-time cashflow KPIs, category spending analytics, trilingual UI (`EN / DE / FA`) with Toman/Euro/Dollar localization, live search/filtering, and `localStorage` persistence.                                                                                    |  [View Live](https://alirezabaghbanicode.github.io/js-practical-projects/01-expense-tracker/?lang=en)  |
| **02** | **NexusBoard — Enterprise Agile Kanban & Sprint Analytics**    | 4-column agile Kanban workspace with zero-dependency SVG Donut & Column charts, percentage workload analytics, subtask checklists, localized EN/DE/FA Jalali calendar, dark/light themes, JSON export, and trilingual `EN / DE / FA` UI.                            | [View Live](https://alirezabaghbanicode.github.io/js-practical-projects/02-kanban-task-board/?lang=en) |
| **03** | **FocusHabit OS — Deep Work, Habits & Recovery Tracker**       | Drift-free Web Audio Pomodoro timer, daily habit builder, live sobriety & quit-smoking trackers with trigger diagnostics, privacy blur mode, 365-day SVG heatmap, and trilingual EN/DE/FA Jalali calendar.                                                          |  [View Live](https://alirezabaghbanicode.github.io/js-practical-projects/03-focus-habit-os/?lang=en)   |
| **04** | **ALIREZA Runway — Interactive 3D Lookbook & Styling Studio**  | Spring-physics 3D depth ring (`<runway-section>` Web Component), 10 women's & men's WebP looks with collection filters, Canvas alpha feet detection, inertial custom cursor, FLIP zoom lightbox with hotspot pins, `localStorage` styling bag, and `EN / DE / FA` UI. |  [View Live](https://alirezabaghbanicode.github.io/js-practical-projects/04-alireza-runway/?lang=en)  |

### Engineering Highlights

- **Predictable State Flow:** Single-source-of-truth data model separated from DOM rendering logic, backed by `@ts-check` JSDoc static type checking.
- **Performance & Security:** GPU-composited animations (`translate3d`), event delegation for dynamic lists, strict Content Security Policy (CSP), `Intl.NumberFormat` localization, and HTML escaping against XSS.
- **Responsive & Accessible UI:** Fluid desktop/mobile layouts, automatic RTL/LTR direction switching, and semantic landmarks.

### Technische Schwerpunkte

- **Saubere Zustandsverwaltung:** Klare Trennung zwischen Datenmodell und Benutzeroberfläche (DOM-Rendering) mit `@ts-check`-Typprüfung.
- **Performance & Sicherheit:** GPU-beschleunigte Animationen (`translate3d`), Event-Delegation für dynamische Listen, Währungsformatierung mit `Intl.NumberFormat` und Schutz vor XSS.
- **Responsives UI-Design:** Moderne, barrierefreie Oberflächen für Desktop- und Mobilgeräte.

<h3 dir="rtl">ویژگی‌های فنی و استانداردهای کدنویسی</h3>

<ul dir="rtl">
  <li><strong>معماری تک‌منبع حقیقت (Single Source of Truth):</strong> جداسازی کامل منطق داده‌ها از لایه نمایش DOM همراه با تایپ‌چکینگ ایستا (<code>@ts-check</code>) برای نگهداری آسان و بدون باگ.</li>
  <li><strong>بهینه‌سازی و امنیت:</strong> انیمیشن‌های سخت‌افزاری روی GPU (<code>translate3d</code>)، استفاده از Event Delegation، سیاست امنیت محتوا (CSP)، فرمت‌بندی استاندارد اعداد و واحدهای پولی با <code>Intl.NumberFormat</code> و پاک‌سازی ورودی‌ها در برابر XSS.</li>
  <li><strong>رابط کاربری واکنش‌گرا و سه‌زبانه:</strong> تغییر خودکار چیدمان راست‌به‌چپ (RTL) و چپ‌به‌راست (LTR) متناسب با زبان انتخابی کاربر.</li>
</ul>
