## 🇬🇧 English — Portfolio Overview

Welcome to my **Practical JavaScript Projects** repository. Each application in this collection is engineered from scratch using **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)** without external frameworks—demonstrating core frontend fundamentals, clean state flow, and responsive interface design.

### Live Applications

|   #    | Project                                   | Description & Core Concepts                                                                                                          |                                          Live Demo                                           |
| :----: | :---------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------: |
| **01** | **LedgerFlow — Expense & Budget Tracker** | Real-time cashflow KPIs, category spending analytics, live search/filtering, XSS-safe DOM rendering, and `localStorage` persistence. | [View Live](https://alirezabaghbanicode.github.io/js-practical-projects/01-expense-tracker/) |

### Engineering Highlights

- **Predictable State Flow:** Single-source-of-truth data model separated from DOM rendering logic.
- **Performance & Security:** Event delegation for dynamic lists, `Intl.NumberFormat` currency localization, and HTML escaping against XSS.
- **Responsive & Accessible UI:** Fluid layouts, keyboard-friendly controls, and semantic landmarks.

## 🇩🇪 Deutsch — Projektübersicht

Willkommen in meinem Repository **Praktische JavaScript-Projekte**. Jede Webanwendung in dieser Sammlung wurde von Grund auf mit **HTML5**, **CSS3** und **Vanilla JavaScript (ES6+)** ohne externe Frameworks entwickelt, um saubere DOM-Architektur, Zustandsverwaltung und modernes UI-Design zu demonstrieren.

### Live-Anwendungen

|   #    | Projekt                                    | Beschreibung & Kernkonzepte                                                                                                          |                                            Live-Demo                                            |
| :----: | :----------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------: |
| **01** | **LedgerFlow — Haushalts- & Budgetplaner** | Echtzeit-Finanzübersicht, Ausgabenanalyse nach Kategorien, Live-Suche und Filterung sowie dauerhafte Speicherung via `localStorage`. | [Live ansehen](https://alirezabaghbanicode.github.io/js-practical-projects/01-expense-tracker/) |

- **Saubere Zustandsverwaltung:** Klare Trennung zwischen Datenmodell und Benutzeroberfläche (DOM-Rendering).

## 🇮🇷 فارسی — معرفی مخزن و پروژه‌ها

به مخزن **پروژه‌های کاربردی جاوااسکریپت** خوش آمدید. تمامی اپلیکیشن‌های این مجموعه بدون استفاده از فریم‌ورک‌های آماده و به‌صورت خالص با **HTML5**، **CSS3** و **Vanilla JavaScript (ES6+)** پیاده‌سازی شده‌اند تا تسلط بر معماری DOM، مدیریت وضعیت (State Management)، کار با APIهای مرورگر و طراحی رابط کاربری مدرن را به نمایش بگذارند.

### پروژه‌های فعال (دموی زنده)

### ویژگی‌های فنی و استانداردهای کدنویسی

- **معماری تک‌منبع حقیقت (Single Source of Truth):** جداسازی کامل منطق داده‌ها از لایه نمایش DOM برای نگهداری آسان و بدون باگ.
- **بهینه‌سازی و امنیت:** استفاده از Event Delegation برای مدیریت رویدادها، فرمت‌بندی استاندارد اعداد و ارزها با `Intl.NumberFormat` و پاک‌سازی رشته‌های ورودی کاربر.
- **رابط کاربری واکنش‌گرا (Responsive):** طراحی مدرن، سازگار با موبایل و دسکتاپ و رعایت اصول دسترسی‌پذیری وب.
