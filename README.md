## <img src="./assets/flag-for-flag-united-kingdom-svgrepo-com.svg" width="22" alt="UK Flag" /> English — Portfolio Overview

Welcome to my **Practical JavaScript Projects** repository. Each application in this collection is engineered from scratch using **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)** without external frameworks—demonstrating core frontend fundamentals, clean state flow, and responsive interface design.

### Live Applications

|   #    | Project                                                     | Description & Core Concepts                                                                                                                                                                                                              |                                               Live Demo                                                |
| :----: | :---------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------: |
| **01** | **LedgerFlow — Expense & Budget Tracker**                   | Real-time cashflow KPIs, category spending analytics, trilingual UI (`EN / DE / FA`) with Toman/Euro/Dollar localization, live search/filtering, and `localStorage` persistence.                                                         |  [View Live](https://alirezabaghbanicode.github.io/js-practical-projects/01-expense-tracker/?lang=en)  |
| **02** | **NexusBoard — Enterprise Agile Kanban & Sprint Analytics** | 4-column agile Kanban workspace with zero-dependency SVG Donut & Column charts, percentage workload analytics, subtask checklists, localized EN/DE/FA Jalali calendar, dark/light themes, JSON export, and trilingual `EN / DE / FA` UI. | [View Live](https://alirezabaghbanicode.github.io/js-practical-projects/02-kanban-task-board/?lang=en) |

### Engineering Highlights

- **Predictable State Flow:** Single-source-of-truth data model separated from DOM rendering logic.
- **Performance & Security:** Event delegation for dynamic lists, strict Content Security Policy (CSP), `Intl.NumberFormat` localization, and HTML escaping against XSS.
- **Responsive & Accessible UI:** Fluid layouts, automatic RTL/LTR direction switching, and semantic landmarks.

## <img src="./assets/flag-for-flag-germany-svgrepo-com.svg" width="22" alt="Germany Flag" /> Deutsch — Projektübersicht

Willkommen in meinem Repository **Praktische JavaScript-Projekte**. Jede Webanwendung in dieser Sammlung wurde von Grund auf mit **HTML5**, **CSS3** und **Vanilla JavaScript (ES6+)** ohne externe Frameworks entwickelt, um saubere DOM-Architektur, Zustandsverwaltung und modernes UI-Design zu demonstrieren.

### Live-Anwendungen

|   #    | Projekt                                           | Beschreibung & Kernkonzepte                                                                                                                                                                                                      |                                                 Live-Demo                                                 |
| :----: | :------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------: |
| **01** | **LedgerFlow — Haushalts- & Budgetplaner**        | Echtzeit-Finanzübersicht, Ausgabenanalyse nach Kategorien, dreisprachige Oberfläche (`EN / DE / FA`), Live-Suche und dauerhafte Speicherung via `localStorage`.                                                                  |  [Live ansehen](https://alirezabaghbanicode.github.io/js-practical-projects/01-expense-tracker/?lang=de)  |
| **02** | **NexusBoard — Agiles Kanban & Sprint-Analytics** | 4-Spalten-Kanban-Board mit interaktiven SVG-Kreis- und Säulendiagrammen, Prozent-Auslastungsanalyse, Checklisten, lokalisiertem EN/DE/FA-Kalender, Dark/Light-Theme, JSON-Export und dreisprachiger Oberfläche (`EN / DE / FA`). | [Live ansehen](https://alirezabaghbanicode.github.io/js-practical-projects/02-kanban-task-board/?lang=de) |

### Technische Schwerpunkte

- **Saubere Zustandsverwaltung:** Klare Trennung zwischen Datenmodell und Benutzeroberfläche (DOM-Rendering).
- **Performance & Sicherheit:** Event-Delegation für dynamische Listen, Währungsformatierung mit `Intl.NumberFormat` und Schutz vor XSS.
- **Responsives UI-Design:** Moderne, barrierefreie Oberflächen für Desktop- und Mobilgeräte.

<h3 dir="rtl">ویژگی‌های فنی و استانداردهای کدنویسی</h3>

<ul dir="rtl">
  <li><strong>معماری تک‌منبع حقیقت (Single Source of Truth):</strong> جداسازی کامل منطق داده‌ها از لایه نمایش DOM برای نگهداری آسان و بدون باگ.</li>
  <li><strong>بهینه‌سازی و امنیت:</strong> استفاده از Event Delegation برای مدیریت رویدادها، سیاست امنیت محتوا (CSP)، فرمت‌بندی استاندارد اعداد و واحدهای پولی با <code>Intl.NumberFormat</code> و پاک‌سازی ورودی‌ها در برابر XSS.</li>
  <li><strong>رابط کاربری واکنش‌گرا و سه‌زبانه:</strong> تغییر خودکار چیدمان راست‌به‌چپ (RTL) و چپ‌به‌راست (LTR) متناسب با زبان انتخابی کاربر.</li>
</ul>
